Electrostatic supports two primary setup paths:

1. JBang + CLI for local development and script-first workflows.
2. Maven plugin for Maven-based projects and CI pipelines.

## Choose your path

- [Install with JBang and use the CLI](jbang-cli-installation.html)
- [Install and run with Maven](maven-cli-installation.html)

## Minimum requirements

- Java 21 or newer.
- Internet access for dependency download on first run.

If you already use Maven in your project, start with the Maven page. If you want the fastest zero-setup trial, start with JBang.
