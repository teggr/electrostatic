---
title: Electrostatic
description: A Java static site generator you can run with JBang or Maven and publish to GitHub Pages.
---

Electrostatic is a Java static site generator. Write content in Markdown, pick a theme, and build a fast static site with JBang or the Maven plugin.

New here? Start with [Installation](installation/index.html), then follow [Publish to GitHub Pages](guides/github-pages-guide.html) to deploy your site automatically with GitHub Actions. This site is built with Electrostatic and published the same way.
