## What it is for

`PostsPlugin` creates a dedicated posts archive with pagination.

## Inputs

- Indexed content items (typically posts).

## Output behavior

- Generates archive pages such as `/posts/page/2/index.html`.
- Provides paginated access beyond the homepage index.

## Use case

Use this plugin when you want a browsable long-form archive separate from the front page.
