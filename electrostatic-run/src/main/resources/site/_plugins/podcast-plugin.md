## What it is for

`PodcastPlugin` reads episode content from `_podcasts/` using markdown and frontmatter.

## Inputs

- Folder: `_podcasts/`
- File type: `.md`
- Metadata usually includes title, date, and description.

## Output behavior

- Adds podcast content items to the site model.
- Enables podcast-specific rendering in theme layouts.

## Example use case

Publish a weekly episode page alongside blog posts and feeds.
