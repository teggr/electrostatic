## What it is for

`CategoriesPlugin` aggregates categorized content and generates category pages.

## Inputs

- Content that includes category metadata.

## Output behavior

- Generates category pages at paths like `/categories/{category}/index.html`.
- Helps readers navigate broad content areas.

## Typical usage

Use categories for high-level classification (for example: releases, guides, tutorials), and tags for finer-grained topics.
